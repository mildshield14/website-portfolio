# Vennila Sooben — portfolio

Personal portfolio for [Vennila Sooben](https://vennilasooben.dev), a Montréal-based software developer working across AI-assisted workflow automation, Microsoft Power Platform, frontend engineering, and prompt engineering research.

## Focus areas

- TypeScript, Python, JavaScript, Vue 3, Nuxt, and React
- Power Apps, Power Automate, Dataverse, Power BI, and Copilot Studio
- Academic LLM application development with prompt engineering, RAG, LangChain, and CrewAI
- Accessible interfaces, design systems, process analysis, and automation

## Local development

```bash
npm ci
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Search and machine-readable files

- `robots.txt` declares crawler access and the sitemap location.
- `sitemap.xml` lists canonical public pages.
- `llms.txt` provides a concise, source-linked professional summary.
- The homepage includes `ProfilePage` and `Person` JSON-LD plus crawlable fallback content.
